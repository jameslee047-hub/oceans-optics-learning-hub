# Oceans Optics Learning Hub Editor Guide

Use Google Docs Suggesting mode for edits.

## Tone

Oceans Optics Learning Hub copy should feel:

- knowledgeable
- friendly
- practical
- instructor-led
- beginner-friendly
- clear
- not corporate
- not overly technical
- not unnecessarily sales-focused

Use US English.

## Editor May Improve

- grammar
- clarity
- wording
- flow
- repetition
- headings
- sentence structure
- concision
- tone consistency

## Editor Should Not Independently Add

- unsupported technical claims
- unsupported safety claims
- unsupported medical claims
- unsupported scientific claims
- unsupported product-performance claims

Do not silently change factual meaning.

If new factual information would improve a lesson, mark it like this instead of adding it as established fact:

`[EDITOR SUGGESTION — VERIFY: ...]`

## Knowledge Checks

Knowledge-check correct answers must remain clearly identified.

Knowledge-check correct answers must remain factually consistent with the lesson.

The website interaction is handled separately; the editor is reviewing question wording, answer wording, and explanation wording.
