# Editorial Standards

These standards apply to all Learning Hub content developed under `content-development/`.

## Language Standard

Oceans Optics uses US English.

Use:

- snorkeling
- snorkeler
- equalizing
- recognize
- behavior
- color
- minimize
- maximize
- judgment
- signaling
- recognized guidance

Avoid mixed spelling inside drafts, metadata, review notes, and future slugs.

## Standard Terminology

Use these terms consistently:

- dual-lens mask
- single-lens mask
- open-heel fins
- closed-heel fins
- shallow-water blackout
- breath-hold
- pre-snorkel
- rip current

Use `rip current`, not `riptide`. Only use `riptide` when explaining that it is a common but inaccurate term.

## Public vs Internal Content

Public lesson drafts should read like original Oceans Optics educational content.

Do not include these internal concepts in reader-facing copy:

- recovered guide
- recovered content
- original Genially
- source material
- extracted page
- source file

Do not include internal review markers in reader-facing copy:

- `[SAFETY REVIEW REQUIRED]`
- `[CURRENT GUIDANCE CHECK REQUIRED]`
- `[CONTENT GAP]`
- `[INSTRUCTOR INPUT OPPORTUNITY]`

If a claim is too uncertain to publish, remove it from the public draft and capture the missing requirement in internal metadata or editorial notes. Do not silently treat unverified claims as approved.

## Internal Review Markers

Use these markers only in internal metadata or editorial notes:

- `[CONTENT GAP]` for missing content that needs research or instructor knowledge.
- `[INSTRUCTOR INPUT OPPORTUNITY]` for places where genuine Oceans Optics instructor/founder experience should be added.
- `[SAFETY REVIEW REQUIRED]` for safety claims, warnings, or procedures that need expert review.
- `[CURRENT GUIDANCE CHECK REQUIRED]` for guidance that may vary by region, organization, season, recognized safety advice, or time.

## Safety Publication Rule

Any lesson tagged with one or more of the following requires a named reviewer before `Publication readiness` can become `Ready`:

- safety
- medical
- first aid
- breath-hold
- shallow-water blackout
- equalizing
- current guidance

Keep these fields separate:

- Author
- Reviewer
- Last reviewed

`Last reviewed` means the date factual/editorial review was actually completed. It is not the date the file was edited.

## Structured Placeholders

Use predictable internal placeholders:

- `[TOOL: mask-sizing-tool]`
- `[TOOL: underwater-lens-calculator]`
- `[PRODUCT: prescription-mask-collection]`
- `[DOWNLOAD: pre-snorkel-checklist]`
- `[CTA: find-your-mask]`

Do not invent URLs.

The `Primary CTA` field is optional. Safety, science, and conservation lessons do not need a commercial CTA simply to fill the field.

## Knowledge Check Format

Keep knowledge checks inside Markdown lesson files for now. Use this format:

```markdown
### Knowledge Check

**Q1. Question text**

- A. Answer
- B. Answer
- C. Answer

**Correct:** B

**Explanation:** Short explanation.
```

Not every lesson requires a quiz. Include one only when it improves learning or retention.

## Visual Fields

Use these fields:

- `hero_media`: public field for a published image, diagram, video, or other main media asset.
- `visual_brief`: internal field for visual direction.
- `visual_status`: internal field for visual production state.

Suggested `visual_status` values:

- none needed
- recommended
- required
- asset available
- needs design

Do not use `recommended visual` as a future public Shopify content field.
