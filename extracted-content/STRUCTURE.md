## Branching and Repeated Navigation

- Most main content pages include a home/index icon or button returning to slide 002 `INDEX`.
- Section menus branch to their child pages and back to the main menu.
- Popup/modal slides are reached by `slidePopup` actions and usually close through `closeSlidePopup` actions.
- `zoom` actions appear on some image/icon elements and should be manually reviewed for visual intent.
- `showElements` actions appear in the data and may represent staged/revealed content.
- One `playAudio` action references the local MPGA file in `/audios`.
- External `openLink` actions reference Genially/LinkedIn URLs and are catalogued in the content inventory.
